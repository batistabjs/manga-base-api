Endpoints da API & autenticação JWT

Integre seu leitor, app mobile ou bot com a base localhost:8081. Todas as rotas abaixo estão ativas neste servidor.

Endpoints públicos (sem token)

  • GET/api/v1/mangascatálogo paginado
  • GET/api/v1/mangas/{id}detalhes por ID
  • GET/api/v1/mangas/tipo/{tipo}manga | manhwa | gibi
  • GET/api/v1/mangas/status/{status}filtro de status
  • GET/api/v1/mangas/genero/{genero}filtro por gênero
  • GET/api/v1/mangas/ano/{ano}filtro por ano
  • GET/api/v1/mangas/buscar?q={termo}busca textual
  • GET/api/v1/mangas/estatisticascontadores

Operações autenticadas (Bearer JWT)

Envie o cabeçalho Authorization: Bearer <token>.

  • POST/api/v1/auth/cadastrocriar conta + token
  • POST/api/v1/auth/loginobter token
  • GET/api/v1/auth/medados do usuário
  • POST/api/v1/mangascriar obra
  • PUT/api/v1/mangas/{id}editar obra
  • DEL/api/v1/mangas/{id}excluir obra
auth_fetch_example 
curl -X POST http://localhost:8081/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@mangabase.com", "senha": "123456"}'

# 2. Consultar o catálogo com o token recebido:
curl -X GET http://localhost:8081/api/v1/mangas \
  -H "Authorization: Bearer SEU_TOKEN_AQUI"
// 1. Login e obtenção do token
const resposta = await fetch('http://localhost:8081/api/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'admin@mangabase.com', senha: '123456' })
});
const { token_gerado } = await resposta.json();

// 2. Leitura com Bearer Token
const mangas = await fetch('http://localhost:8081/api/v1/mangas', {
  headers: { Authorization: `Bearer ${token_gerado}` }
}).then((r) => r.json());
console.log(mangas);
